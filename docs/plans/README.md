# Feature Plans & Design Documents — UNB Wire

> Directory for high-level architectural proposals, technical RFCs, and feature designs.

---

## 1. Structure

Feature design documents are authored by the **Architect** before planning and implementation:
```
docs/plans/<feature-slug>-design.md
```

Each plan should cover:
1. **Problem Statement & Requirements**
2. **Architecture & Component Boundaries**
3. **Data Model & Schema Impact**
4. **API Contracts / Wire Payload Specs**
5. **Security, RBAC & Subscription Boundaries**
6. **Task Decomposition Outline** (for Planner handoff)
